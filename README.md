# Projeto de Pandas
Aqui estão comandos em pandas explicados para auxiliar no uso dos recursos da biblioteca pandas.
Aqui está um resumo de todos os temas e recursos abordados no arquivo Codigos_iniciais_Pandas:
  * Importação da Biblioteca
  * Estruturas Básicas em Pandas
  * Criação de objetos em Pandas
  * Importação de arquivos em Pandas
  * Visualização dos dados
  * Conversão de DataFrame
  * Seleção de itens no DataFrame
    * Seleção por posição
    * Seleção por valor booleano
  * Inserção de dados em um DataFrame
  * Valores nulos
  * Eliminação de dados
  * Operação com Séries usando Pandas
  * Operação simples com o Dataframe:  usando a função contar, colunas, soma, seleção por tipo de dados, minima, máximo, index do valor mínimo e máximo
  * Operações estatísticas: média, mediana, subtração com series em dataframes
  * Usando funções matemáticas em dataframes
  * Contando valores em séries pandas
  * Usando métodos de Strings
  * Concatenando Dataframes usando as funções Join e Groupby
  * MultiIndex e funções Stack e Pivot Table
  * Séries temporais com pandas
  * Usando a função Categoricals
  * Plotando gráficos com Pandas
  * Importando dados específicos de arquivos
  * Pegando informações de JSON
  * Usando Banco de dados com Pandas
  * Exportando dados para .CSV
  * Importando e Exportando dados para Parquet e Excel

Este repositório servira como um local de armazenamento para comandos úteis em pandas porém não contém todos os comandos.
Este repositório também será usado para eventuais testes de funções e comandos da biblioteca Pandas. Sempre utilizado com cuidado.
